  2. Mobile review: responsive-design mode at 390×844 (iPhone 12/13/14 size) is what this pass was verified against.

Security / sanitization

  1. No production Supabase project URL and no production publishable key are embedded anywhere in this mirror — dashboard.js's SUPABASE_URL/SUPABASE_ANON are inert placeholders (review-mirror-fixture.invalid), kept only because one dead fallback branch in boot() references the identifiers syntactically; that branch never actually runs here.
  2. No Supabase SDK is loaded — the @supabase/supabase-js CDN script has been removed entirely. Fixture auth.js and repository.js provide 100% of the mirror's authentication and data.
  3. No Netlify environment values, no authentication of any kind.
  4. No production API calls — open your browser's Network tab; the only cross-origin request you'll ever see is nothing at all (no external requests remain after this pass).
  5. No write operations reach anywhere outside this browser tab's memory; nothing persists past a reload.
  6. No real signal text, member data, or private notes — every fixture uses example.com URLs and fabricated content.
  7. Run node sanitization-check.js from this repository to verify all of the above automatically — see the file for what it checks.
